# Auth service

Сервис авторизации и контроля доступа для приложения управляющей компании. Здесь размещаются API аутентификации, пользователи, роли и политики доступа.

Текущий каталог содержит зависимости и настройки тестов/Alembic, но пока не содержит реализацию сервиса. Технологический каркас следует согласовать с командным API-контрактом.
