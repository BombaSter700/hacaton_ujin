# Backend services

Каждый подкаталог — отдельный сервис или самостоятельный инструмент. Общие API-контракты и договорённости между сервисами фиксируйте в `docs/`.

- `auth/` — авторизация и права доступа.
- `integration/` — интеграция с IoT-платформами.
- `emulators/` — эмуляторы устройств для локальной разработки интеграции.
