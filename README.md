# Ujin IoT ERP

Хакатонный проект веб-приложения для управляющей компании: единая панель для работы с IoT-устройствами жилых объектов.

## Сервисы

- `backend/auth` — сервис авторизации и управления доступом.
- `backend/integration` — сервис интеграции с платформой Ujin и другими IoT-системами.
- `backend/emulators` — эмуляторы устройств и локальные инструменты для разработки и демонстрации интеграций.
- `frontend/admin-panel` — веб-панель УК.
- `infra` — инфраструктурные скрипты.

Сервисы разрабатываются независимо и взаимодействуют через API. Сейчас проект находится на  стадии MVP;

## Локальный запуск всех контейнеров

Для локального запуска всего проекта используем корневой скрипт `start.sh`.
Нужны установленный и запущенный Docker с Docker Compose v2 и shell
(на Windows — Git Bash или WSL).

```sh
bash start.sh
```

Скрипт включает профили `backend` и `frontend`, собирает образы, запускает
все сервисы из `docker-compose.yml` в фоне, ждёт их готовности и выводит статус.
Это PostgreSQL 18, KrakenD, Redis 7, ClickHouse 25.3, эмуляторы IoT,
сервисы авторизации и интеграции, а также веб-панель УК.
Повторный вызов применяет изменения и пересобирает образы.
Дополнительные параметры передаются в `docker compose up`, например:

```sh
bash start.sh --wait-timeout 180
```

Compose автоматически читает корневой `.env`; без него используются значения
по умолчанию для локальной разработки. При необходимости измените порты и
учётные данные в `.env`. Не используйте локальные пароли в общих окружениях.
PostgreSQL создаёт `auth_db` и `integration_db` при первом запуске с пустым томом.

Адреса по умолчанию:

- Веб-панель: http://localhost:3000
- API-шлюз: http://localhost:8080; проверка состояния: http://localhost:8080/__health
- Авторизация: http://localhost:8001
- Интеграция: http://localhost:8002
- Состояние эмуляторов: http://localhost:8098/health; порты устройств: 8099–8107.

Логи и остановка всех контейнеров с сохранением данных (из корня проекта):

```sh
docker compose --profile backend --profile frontend logs -f
docker compose --profile backend --profile frontend down
```
